# Development

`minimus` is an original terminal-based internet radio player developed for MINIX 3.

The application was developed through iterative AI-assisted collaboration with ChatGPT. Much of the source code was generated or refined during this collaboration, with the resulting code compiled, tested, debugged, and validated on a 
MINIX 3 system.

Development and testing were performed on MINIX 3 running in a QEMU/KVM virtual machine. The application uses `mpg123` for audio playback and supports PLS playlists, station selection, playback controls, track metadata, and persistent 
configuration.

The project is experimental and has not been tested on other operating systems.
